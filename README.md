One-page website for a certified Shantala baby massage instructor in Warsaw (in Polish).

## What's inside

- Offer with prices and bonuses, workshop steps, FAQ, contact and a referral box
- **Moderated reviews and questions:** visitors submit a Google Form; the owner approves entries in Google Sheets by typing "TAK", and approved entries appear on the site automatically (published CSV, fetched in the browser, no server)
- Blog with a first article, a step-by-step guide to foot massage
- Responsive layout, optimized images, accessible markup

## Tech

Plain HTML, CSS and JavaScript · Google Forms + Google Sheets as a lightweight CMS · GitHub Pages
